
# Company-Smart Mock Interview Coach

## Overview
An AI-powered mock interview preparation system that helps students prepare for company-specific technical interviews.

## Features
- Company and job role selection
- AI-generated interview questions
- Automated answer evaluation
- Personalised interview coaching
- Final performance report

## AI Agents
1. Interviewer Agent
2. Evaluator Agent
3. Coach Agent
4. Report Agent

## Technologies Used
- Python
- Streamlit
- Ollama (Gemma 3:1b)
- LangChain
- ChromaDB

## Installation

Install dependencies:

pip install -r requirements.txt

Run Ollama:

ollama run gemma3:1b

Run the application:

streamlit run app.py

Agentic AI – Assignment 1
